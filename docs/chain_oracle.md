# 오라클 한 수 앞보기 (사슬 방향의 천장 시험)

날짜 2026-11-02. 결과를 보기 전에 정한 기준.

## 질문
학습된 동역학 모델의 오차를 전부 없애고(시뮬레이터가 계산한 정답 다음 상태를 줌) 가치망 V로만 읽으면 Q 정책이 정책 헤드보다 나아지는가.
나아지지 않으면 병목은 동역학이 아니라 가치 함수이므로 사슬/동역학 방향은 접는다.

## 방법
- 위치: `data/cf/main.jsonl`의 300개 (팀 풀 holdout, 임의 접두 0~4턴). 칸 (내 행동 a, 상대 응수 클래스 o)의 대표 응수 하나, 난수 1개(rep 0).
- 다음 상태: 시뮬레이터가 한 턴 진행한 상태를 FP 재생으로 인코더 입력으로 만들고(`tools/cf_oracle_scenes.py`, `tools/cf_run.sh`), 모델 V를 읽음. 내 포켓몬이 기절해 강제 교체가 걸린 칸은 들어올 수 있는 포켓몬마다 한 장면씩 더 만들고 V의 최댓값을 씀.
- Q_oracle(a) = Σ_o w(o) V(s'_{a,o}). w는 (i) 모델 p(o|s) (ii) 균등 (iii) 최악 응수(min)를 모두 보고하되 주 결과는 (i).
- 정답 라벨: 같은 위치를 FP 300ms로 다시 라벨한 q_mean (방문 >= 100인 행동만, 신뢰 가능한 행동 2개 이상인 위치만).
- 비교: 같은 모델 M의 정책 헤드 argmax regret 대비 Q_oracle argmax regret. 위치 단위 짝지은 부트스트랩.
- 모델 M: v8_full, v8m, chain_p1_rt_all (V와 정책 헤드를 같은 모델에서 읽음).

## 판정 (사전 등록)
- 살린다: Q_oracle regret이 정책 헤드보다 0.003 이상 낮고 짝지은 95% 구간이 0을 포함하지 않음.
- 접는다: 차이가 0.003 미만이거나 Q_oracle이 더 나쁨.
- 위치 300개로는 검정력이 약하므로(위치당 차이의 표준편차 약 0.06 가정, SE 약 0.0035) 차이의 점추정이 0.003~0.006이고 구간이 0을 걸치면 위치를 늘려 한 번 더 한다. 그 이후에는 결과대로 판정한다.
- 보조 진단: Q_oracle과 FP q_mean의 위치별 순위 상관, 정책 로짓과 q_mean의 순위 상관.

## 한계
- 접두가 임의 수라 초반 위주의 비전형 상태. 절대 regret은 학생 상태 세트의 값과 직접 비교 불가.
- 난수 1개짜리 한 턴 결과라 V에 표본 노이즈가 섞임 (오라클의 하한을 낮추는 방향).
- 한 턴 앞이므로 FP 탐색(깊은 앞보기)의 대체물이 아니라 "한 턴 동역학이 가치망에 주는 정보"만 잼.

## 추가 시험: 모델 V를 FP 탐색 가치로 바꿔 끼우기 (2026-11-02, 결과 보기 전에 정함)
- 20ms 재생의 teacher_value는 같은 위치 안에서 한 턴 체력 이득과 상관 0.06(모델 V는 0.39)이라 노이즈였음 → 무효. 마지막 결정만 300ms로 다시 재생(`REPLAY_LAST_MS`, `CF_LAST_MS`, 샤드 orf0~5, 중반 250위치).
- 비교: Q_oracle(FP 가치, 응수 가중) vs 정책 헤드의 argmax regret, 같은 위치 짝지은 부트스트랩. 모델 V 기반 값도 같은 샤드에서 다시 잼.
- 판정(사전 등록): 
  - 크게 이김 = FP가치 Q regret이 정책보다 0.003 이상 낮고 95% 구간이 0을 포함하지 않음 → 사용자 결정에 따라 V를 대대적으로 고침(분리한 가치망을 FP 탐색 가치에 맞춰 학습, 평가는 같은 오라클 시험).
  - 이기지 못함 = 한 수 앞보기 구조 자체가 막힌 것으로 보고 V 개편은 하지 않음.
- 해석 주의: 이 값은 평가 함수가 아니라 300ms 탐색 뒤의 루트 가치라 FP 탐색 비용이 섞인 상한. 이겨도 "모델이 그 값을 낼 수 있다"는 증거가 아님 → 같은 데이터로 모델 V가 FP 값 변동을 얼마나 맞히는지(위치 내 상관, 설명 비율)를 반드시 같이 보고, V 개편의 목표치를 거기서 정함.

### 결과 (2026-11-02, 중반 250위치, 마지막 결정 300ms, 샤드 orf0~5)
- v8m 정책 0.0109 vs FP 가치 Q_oracle 0.0990 (균등 0.0950): 차이 +0.088 [0.078,0.099], 무작위(0.0839)보다도 나쁨. v8_full도 같음(0.0990). q_mean과 위치 내 순위 상관 -0.099. 기준(정책보다 0.003 이상 낮음) 미충족 → V 대대적 개편은 이 근거로 하지 않음.
- 값 자체는 정상: FP 가치(s')의 위치 평균이 같은 위치 FP 루트 가치와 상관 0.69(방향·정렬 맞음), 마지막 결정의 98.5%가 300ms로 탐색됨(방문 중앙값 18.3만).
- 그런데 같은 위치 안에서 행동별로는 안 맞음: 행동 a별 평균 FP 가치(s'_a)와 FP q_mean(a)의 위치 내 상관 -0.10, 한 턴 체력 이득과의 상관 0.05(모델 V는 0.39). 행동 사이의 실제 차이(0.02~0.05)가 FP 값 한 번의 변동(탐색 표본 세계, 상대 응수에 따른 믿음 변화)보다 작아서 한 수 앞보기로는 가려낼 수 없음. 탐색은 같은 상태를 수만 번 평균해서 이 변동을 지움.
- 부수 발견: 모델 V(v8m)의 위치 평균은 FP 루트 가치와 상관 0.12뿐(FP 값은 0.69). 절대적인 상태 평가는 FP와 많이 다름 → 장기 유불리 평가 진단은 별도로 가치 있음(한 수 앞보기와 무관).
