# M5 반사실 검증 (2026-11-01, 결과 보기 전에 기준을 적어 둠)

## 질문
결과 헤드 `r(s,a,o)`가 **안 둔 수**에 대해서도 한 턴 뒤 변화를 맞추는가? (학습 라벨은 둔 수와 실제 응수 쌍에만 있음 → 사슬 동역학을 검색에 쓸 수 있는지의 전제)

## 방법 (`tools/cf_gen.js`, `cf_scenes.py`, `cf_run.sh`, `cf_eval.py`)
- 위치: metamon 홀드아웃 팀 풀에서 임의 두 팀, 임의 합법 수 0~4턴 접두 (기술 위주, 교체 15%, 테라 7%) 뒤 p1 일반 결정. 임의 접두라 실제 분포보다 거칠다 (한계).
- 정답: 위치에서 내 모든 합법 행동 a(기술/테라 기술/교체) x 상대 응수 클래스 대표 수 o (상대 기술의 클래스별 첫 기술 + 교체 1개, 상대 테라 없음)를 시뮬레이터로 한 턴씩, 턴 안 난수만 바꿔 R=3번. 정답 = 반복 평균.
- Δ: 12슬롯 HP 비율 변화, 새 기절. 슬롯은 종 이름으로 맞춤 (시뮬레이터 팀 순서는 교체하면 바뀜). 부스트와 활성 슬롯은 이번엔 비교 안 함.
- 모델 입력은 같은 위치를 FP 재생으로 만든 학생 시점 텐서 (히스토리 포함 시퀀스의 마지막 행). 예측 = `outcome(chain_h[a,o])`.
- 정답 변환 신뢰도: 접두 + 실제 한 턴을 FP 재생 파이프라인에 통과시켜 인코더의 Δ와 비교 (`cf_eval.py equiv`).
- 비교 대상: 0 예측, 위치 평균(a,o를 무시하되 정답 평균을 쓰는 낙관적 기준), 난수 하한 = 반복 분산/R.
- 제외: 판이 끝나거나 한 턴 뒤 요청이 강제 교체/피벗인 칸 (FP가 그 행을 안 남겨 인코더와 비교 불가). 이 칸의 비중을 따로 보고.

## 사전 등록 기준 (깨끗한 칸 기준, 모델 p1 = chain_p1)
- 통과: HP Δ 설명 비율((MSE0-MSE모델)/(MSE0-하한)) >= 0.5 그리고 응수 고정 수 순위 스피어만 평균 >= 0.5 그리고 모델 p(o) 가중 최상위 일치 >= 0.4 (무작위 약 0.08).
- 부분: 설명 비율 0.3~0.5 (a/o 조건부 구조는 있으나 검색에 쓰기엔 부정확).
- 실패: 설명 비율 < 0.3 또는 순위 상관 < 0.3 -> 안 둔 수의 결과를 모르는 모델, 동역학 방향은 학습 방식을 바꾸지 않는 한 접는다.
